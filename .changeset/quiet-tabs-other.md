#### Other tab for PRs no other tab lists

The status bar counts every PR Ridgeline fetched, but ones you approved,
drafts and anything a tab filter dropped weren't listed anywhere. A new
"Shown in other tabs: Hide" tab filter keeps only PRs that no other enabled
tab lists, and a new default Other tab uses it, so the tabs add up to the
count. Existing configs can add it with Reset to defaults under
Settings → Tabs.
